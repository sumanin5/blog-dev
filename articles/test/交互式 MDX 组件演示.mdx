# 交互式 MDX 演示

这是一个真正的 MDX 文件，可以直接在 Markdown 中嵌入 React 组件。

## 1. 普通 Markdown 内容

这是普通的文本段落，支持 **粗体**、*斜体*、`代码`等。

## 2. 内联 JSX 组件

下面是一个简单的按钮组件：

<div style={{ padding: '20px', background: '#f0f0f0', borderRadius: '8px', margin: '20px 0' }}>
  <p style={{ color: '#333', fontSize: '18px' }}>这是一个内联的 JSX 元素</p>
  <InteractiveButton message="Hello from MDX!">
    点击我
  </InteractiveButton>
</div>

## 3. 代码展示

如果你想展示代码而不是执行它，用代码围栏：

```tsx
import React from 'react';

function MyComponent() {
  return <div>Hello World</div>;
}
```
