## 总结

使用自定义容器语法的优点：

1. ✅ **SEO 友好** - 后端渲染成 HTML
2. ✅ **支持交互** - 前端 hydrate 添加事件
3. ✅ **性能好** - 不需要客户端编译 MDX
4. ✅ **易扩展** - 添加新组件很简单

要添加新组件，只需：
1. 在 `backend/app/posts/custom_components.py` 添加渲染方法
2. 在 `frontend/src/components/mdx/custom-components.tsx` 添加 React 组件
3. 在 `frontend/src/components/post/post-content.tsx` 添加 hydrate 逻辑
